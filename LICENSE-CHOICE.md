# License decision required before publication

The source archive did not contain a `LICENSE` file. No license was assumed or assigned during packaging.

**Decide who owns the copyright and whether you want your source to be open source.** If this is wholly your own code and you want broad permission for reuse, a common option is the MIT License; it permits commercial use, modification, and redistribution subject to its copyright/license notice. If you want redistribution of modified versions under similar terms, consider GPL-3.0-only or GPL-3.0-or-later instead. If you do not want to grant reuse permissions, you may publish source without an open-source license, but it is not open source.

For an MIT choice, use the standard MIT text from https://choosealicense.com/licenses/mit/ and create `LICENSE` in the repository root. Fill in the correct year and copyright holder(s) (the application itself credits Saruhan Çelik). Confirm any collaborators' rights before doing so.

**Also review third-party license obligations:** the Windows binary packages Qt 6 runtime DLLs/plugins and MinGW runtime DLLs. Qt licensing and distribution requirements are separate from the copyright license you select for MIPStudio.
